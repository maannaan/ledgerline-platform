# Runbook: Incident response

**Status:** Skeleton — refine after first real/practice incident.

1. Detect/acknowledge; assign lead + severity.  
2. Blast radius: service, env, tenants, data impact.  
3. Preserve evidence; correlate request/trace/deploy IDs.  
4. Mitigate safely (rollback, scale within cap, isolate tenant).  
5. Verify recovery.  
6. Communicate next update time.  
7. Timeline + follow-ups (feeds PIR).
