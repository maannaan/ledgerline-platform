# 90-Day Engineering Plan

**Status:** Skeleton (≤2 pages when finalized). Expand in Phase 6 from real gaps.

## Days 1–30

Secure baseline, tenant inventory, on-call/incident process, SLO baseline, restore test, release pipeline, runbooks.

## Days 31–60

Onboarding automation, cost attribution, load/capacity model, secrets rotation, security review.

## Days 61–90

Error-budget process, game days, DR exercise, Autopilot maturity, hiring plan.

## First hire

Decide from measured bottlenecks (likely platform/SRE generalist). Justify with toil and risk — not title fashion.
